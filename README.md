## Проекты

### [Student-Urfu-Helper](https://github.com/StefanParmezan/Student-Urfu-Helper)

Pet-проект: backend-сервис для студентов УрФУ.

- REST API на Spring Boot: аутентификация, профиль студента, чаты.
- JWT-аутентификация и Spring Security, BCrypt, CORS.
- PostgreSQL + Spring Data JPA/Hibernate, DTO через MapStruct.
- AI-ассистент на GigaChat: потоковые ответы через SSE и история чатов в БД через кастомный `ChatMemory`.
- Парсинг профиля и курсов УрФУ через Selenium/WebDriver.
- PostgreSQL в Docker Compose.

`Java 24` `Spring Boot 3.5` `Spring Security` `JWT` `PostgreSQL` `JPA/Hibernate` `MapStruct` `WebFlux` `GigaChat` `Selenium` `Docker Compose`

### [RorcikCore](https://github.com/StefanParmezan/RorcikCore)

Рабочий проект: базовая библиотека для модов Rorcik.

- Capability-based система свойств для `ItemStack`: типизированные ключи, дескрипторы, валидация, значения по умолчанию и копирование.
- Реестр свойств и событийная регистрация для модов-зависимостей.
- Городские и биомные зоны, температурные зоны, `SavedData` и правила размещения.
- Реестр идентифицируемых объектов и утилиты сериализации.
- JUnit-тесты для геометрии и границ городских зон.

`Java 17` `Forge 1.20.1` `Capabilities` `JUnit 5`

### [HBM's Nuclear Tech: Well-forged Edition](https://www.curseforge.com/minecraft/mc-mods/ntm-well-forged-edition)

Личный проект: форк индустриального мода HBM's Nuclear Tech Extended Edition для Minecraft 1.12.2.

- Багфиксы и поддержка большой legacy-кодовой базы.
- Асинхронная обработка пакетов и новая система конвейеров.
- Оптимизация производительности и ребаланс механик.

`Java` `Forge 1.12.2`

[CurseForge](https://www.curseforge.com/minecraft/mc-mods/ntm-well-forged-edition) · [GitHub](https://github.com/Glozeysk/Hbm-s-Nuclear-Tech-Waldemar-Edition)
